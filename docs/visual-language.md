# Whiskey · The Personal Journal — 当前视觉规范

更新日期：2026-10-18。本文件是后续网站设计和实现的现行依据；`design/` 中的探索稿、截图和旧说明仅用于历史回顾，不构成当前规范。

## 方向与共享入口

网站采用个人杂志排版：奶油纸底、深蓝油墨、大衬线刊头、细分栏线，以及作品与个人照片构成的真实内容。刊名为 **The Personal Journal**。海岸蓝、泳池、棕榈、港湾场景、玻璃胶囊和装饰性 3D 主图不再是网站设计方向。

`app/visual-language.css` 中的 `--wl-*` 变量是公共站点与 Studio 的共享入口。`app/coastal.css`、部分组件与类名仍沿用历史名称，但当前承担杂志布局；不能仅因名称含 coastal 就删除。新样式使用共享变量，避免引入另一套主题。

## 颜色与字体

- 暖白纸色 `#f4f1e9`、面板 `#faf8f3`、墨蓝标题 `#243743`、正文 `#303a3d`、辅助文字 `#646b69`、赤陶棕强调 `#98664e`、中性分隔线 `#d8d5cc`。
- 墨蓝集中于刊头、标题和关键操作；正文使用近黑色。项目分类使用透明底细边标签，赤陶棕不作为大面积装饰；小字号棕色文字使用稍深的 `#8e5c46`，保障暖白底上的可读性。
- 公开页面使用极淡的棉纸背景纹理 `/images/site-backgrounds/journal-cotton.svg`，不覆盖文字和图片；Studio 保持清晰的平面背景。
- 英文展示使用 Bodoni Moda；中文标题使用 Noto Serif SC。标题通过字号、字重与留白建立层级。
- 文章与项目阅读以 `app/reading.css` 为唯一入口。正文列宽 700px，中文采用苹方 / 微软雅黑 / 系统无衬线字体，18px、1.85 行高；手机 17px。明确标记为英文的正文采用 Lora 19px、1.65 行高。正文不继承展示用衬线字体。
- 阅读标题采用 Inter / 中文系统无衬线字体，正文二级标题 28px、三级 23px；段落间距 1.15em。刊头和首页展示仍使用原有杂志字体。
- 操作控件使用 Inter / 苹方 / 微软雅黑，默认 14px。中文内容保留中文语言标记，不随导航语言切换而压缩字距。
- 使用根布局现有的 Next 自托管字体，不为单页追加外部字体请求。

## 排版与图像

- 首页横向作品目录：作品栏宽、中央索引栏窄；图片、标题和简介自然排列，不靠固定栏高压缩图片。
- 作品缩略图统一采用 3:2 图框，按封面内容设置焦点；重要标题、人物与主体不得被不经检查的居中裁切切掉。需要完整展示的图像改用完整图幅，不在宽框中缩成邮票。
- 页面使用细实线、明确的列与留白建立秩序；正文阅读区不重复套装饰框。既有手记叠卡和书脊保留各自的交互几何，不推广为所有内容的容器。
- 保留本人照片、项目原画和项目真实截图。历史风格资产不是新页面的默认背景；不得因主题清理误删仍在使用的作品素材。
- 分享预览使用 `/images/whiskey-journal-card.png`，不再使用旧场景主图。

## 动效与阅读

项目点击转场采用带封面纹理与撕纸边缘的纸面，由下向上覆盖屏幕，再揭开目标页面。纸面从所点击的作品读取封面；桌面覆盖约 1.1 秒、揭开约 0.9 秒，手机分别约 0.8 秒与 0.65 秒。键盘激活和 `prefers-reduced-motion` 直接导航。此处描述实现参数，实际视觉验收需另外记录。

深蓝可作为首页纸面入场时的舞台色；正文稳定后回到奶油纸面。避免在正文持续旋转、模糊或漂移。项目详情已经使用博客阅读模板，旧版独立项目介绍框、侧边影像按钮和装饰背景不再作为项目页面结构。

项目介绍和博客文章共用 Markdown 渲染、阅读排版与编辑体验。封面、简介、标题和正文图片从项目内容读取；上传保存后的项目进入同一展示数据流，不再为每个项目复制硬编码页面。

渲染覆盖 GFM 表格、嵌套列表、任务列表、删除线、脚注、数学公式、代码高亮、Mermaid、Obsidian 提示块 / 折叠块、高亮、注释、块锚点与已发布笔记内链。安全 HTML 表格继续兼容；正文中的花括号按文字处理，不执行 MDX / JSX 表达式。图片保持原始比例并尊重指定宽度；表格、代码和长公式只在自身区域滚动。

未发布的 vault 笔记、私人附件、跨笔记全文嵌入、Dataview 和其他插件语法不伪装为已支持。安装目录的默认样式与用户 vault 自定义主题属于不同证据范围。具体依据与边界见 `design/reading-2026-10-18/obsidian-evidence.md`。

普通操作至少 44px 高，使用清晰的焦点、禁用和危险操作语义。Studio 与认证页面使用原生滚动，不附加公开展览转场。手机、键盘操作及 `prefers-reduced-motion` 必须可以完成同样的浏览与阅读。

## 验证原则

类型检查、构建与浏览器验证分别记录。修改后检查桌面和手机的图片构图、横向溢出、中文正文、链接、焦点恢复与减少动态效果；内容同步还需验证新建、保存和封面更新。

本规范不是测试通过记录。只有本次实际运行并保留结果的检查才可报告为已验证；本地验证不代表线上已部署，未登录 Studio 时不声称验证过真实上传或发布。

## Studio 表单与列表补充（2026-10-20）

- 字段统一为标签、控件、说明三个区域；同一行从顶部对齐，说明文字不参与分配上方的剩余空间。标签行 20px、输入控件 44px、说明行至少 18px，间距 8px；较长标签组可自然扩展。
- 表单输入、列表操作与既有按钮沿用 `--wl-ui` 和现有字号角色；主操作墨色填充，次操作细边框，危险操作以文字和语义区分，不再另起一套图标与字体。
- 项目与 Notes 列表的编辑、查看、删除对齐同一操作列，手机将操作列移到内容下方。删除进入回收站并可恢复，确认框说明影响与恢复方式。
- 项目动效方案见 `docs/project-motion-proposal.md`；未选定方案前不替换首页浏览交互。
