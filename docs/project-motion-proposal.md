# 项目展示动效提案 · 2026-10-20

方向沿用 The Personal Journal 的奶油纸面、Bodoni Moda / Noto Serif SC 刊头、细分栏线和赤陶色期号。用户已选定 A；正式首页采用报刊翻版，下方样张保留三种历史提案供回顾。

可操作样张：`/prototypes/journal-motion-2026-10-20/index.html`。

| 方案 | 阅读结构与交互 | 适合的情况 | 取舍 |
| --- | --- | --- | --- |
| A 报刊翻版（推荐） | 左右两栏与中央索引；点击期号或上一版/下一版，整版内容依阅读顺序揭开 | 保留现有报刊构图，同时摆脱长条横拖 | 一版只显示两项，需要明确期号和总数 |
| B 纵向分栏 | 自然向下阅读；桌面两栏，手机一栏，段落轻微显现 | 作品数量持续增长，优先快速扫读 | 页面更长，戏剧性较低 |
| C 叠页索引 | 一次聚焦一篇，纸页叠放，主动翻页 | 少量精选作品，强调封面和故事 | 扫描多项目效率较低，不适合作为唯一目录 |

全部方案固定 3:2 纸面画框，图片焦点单独管理；不改变作品素材，不自动轮播，不劫持滚动。键盘和点击均可操作，手机保持相同阅读顺序；减少动态效果时直接切换。

正式实现为 `components/exhibition/newspaper-spread.tsx` 和同名 CSS。纸面覆盖 180ms、右栏错开 40ms；内容在遮合后更换，再以 240ms 展开，标题与简介分别延后 30ms / 60ms。使用强 ease-out `.23,1,.32,1`，整体约 600ms。仅操作 clip-path、transform、opacity，不对布局尺寸做动画。期号立即响应，连续点击合并到最新目标；键盘操作、减少动态效果和动态偏好中途变化直接完成切换。

所有版面共用稳定网格，保留最长标题与简介所需空间；失效封面使用同尺寸刊物字样。手机索引位于图片前，两栏按阅读顺序纵向排列；奇数项目的末版以「下一页，仍在发生」收尾。目录、详情与 Studio 内容同步方式保持一致。

Apple Design 用于层级、熟悉的命令位置、点击区域、焦点和适配；不是替换现有品牌或引入玻璃材质。
