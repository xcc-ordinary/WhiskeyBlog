# 项目展示动效提案 · 2026-10-20

方向沿用 The Personal Journal 的奶油纸面、Bodoni Moda / Noto Serif SC 刊头、细分栏线和赤陶色期号。正式首页先保持现有内容和浏览方式，只统一封面画框。

可操作样张：`/prototypes/journal-motion-2026-10-20/index.html`。

| 方案 | 阅读结构与交互 | 适合的情况 | 取舍 |
| --- | --- | --- | --- |
| A 报刊翻版（推荐） | 左右两栏与中央索引；点击期号或上一版/下一版，整版内容依阅读顺序揭开 | 保留现有报刊构图，同时摆脱长条横拖 | 一版只显示两项，需要明确期号和总数 |
| B 纵向分栏 | 自然向下阅读；桌面两栏，手机一栏，段落轻微显现 | 作品数量持续增长，优先快速扫读 | 页面更长，戏剧性较低 |
| C 叠页索引 | 一次聚焦一篇，纸页叠放，主动翻页 | 少量精选作品，强调封面和故事 | 扫描多项目效率较低，不适合作为唯一目录 |

全部方案固定 3:2 纸面画框，图片焦点单独管理；不改变作品素材，不自动轮播，不劫持滚动。键盘和点击均可操作，手机保持相同阅读顺序；减少动态效果时直接切换。真实上线时还需检验触摸与高缩放状态、快速连续翻页、加载中和封面失败状态。

Apple Design 用于层级、熟悉的命令位置、点击区域、焦点和适配；不是替换现有品牌或引入玻璃材质。
