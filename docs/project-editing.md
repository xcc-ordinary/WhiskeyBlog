# 项目上传、编辑与自动展示

本地打开 `/studio/projects`，使用站长账号登录。新建或选择一个项目，填写名称、简介、日期、标签和 Markdown 正文；Slug 是公开地址的一部分，保存后不可直接修改。

项目正文沿用 Blog 的 Markdown / MDX 渲染组件与阅读样式；标题、列表、引用、代码、图片和链接使用同一套规则。工作台可以切换写作、预览或双栏视图。项目属性收纳在「项目设置」中，手机上按需展开。

## 图片与排版

- 「上传项目封面」支持 JPG、PNG、WebP、GIF，单张最大 3.75MB。上传完成会填写封面地址，保存项目后公开页面同步使用。
- 「插入正文图片」把图片插入光标位置；没有光标位置时追加到末尾。可以直接编辑 Markdown 图片说明。
- 不设置封面时，自动使用正文里第一张 `/images/` 或 `/project-media/` 图片，并使用它的图片说明作为替代文本。代码示例里的图片不会成为封面。没有可用图片时显示统一占位图。
- 首页和项目目录使用统一的图片框。封面模式 `cover` 铺满框，`contain` 完整显示；焦点可填写 `center` 或百分比坐标（例如 `50% 94%`）。设置保存在项目元数据里，不再按项目 Slug 写专门的图片样式。
- 项目详情中的图片按原始比例展示，正文与 Blog 共用阅读栏宽。

## 保存后同步

新项目默认加入首页作品目录，首页、项目列表、详情和工作台读取同一个 `content/projects/*.mdx` 文件。保存会刷新首页、项目列表、当前详情、工作台和站点地图缓存，不需要手动添加项目卡片。

「首页展示与英文设置」中可以取消首页展示，但项目仍保留在项目目录。首页排序是非负整数，数字越小越靠前；同排序按日期从新到旧，再按 Slug 排列。英文名称与简介留空时回退到原文。首页小标签留空时使用首个标签。

上传图片本身不会保存项目文案，仍需点击「保存项目」。删除正文引用不会删除图片文件。项目文件在 `content/projects/`，上传图片文件在 `public/images/projects/uploads/`，通过 `/project-media/文件名` 提供。

## 本地与线上

`npm run dev` 直接读取本地内容；`npm run build` 后 `npm run start` 支持保存后的缓存刷新，新上传图片无需重新构建。前端代码变更仍需重新构建，不要同时让构建和开发服务写同一个 `.next` 目录。

Vercel 上的仓库文件写入仍然停用。本地保存以后，将 MDX 和图片一同通过 Git 发布，线上才会更新；目前没有接入持久化的线上项目 CMS。照片档案继续使用独立的 Supabase 管理流程。

## 当前视觉规范

公共页面遵循 `docs/visual-language.md`：The Personal Journal 的奶油白、深墨蓝、衬线刊头与细分栏。项目数据由工作台维护；刊名、个人简介、首页宣传文案与导航内容仍在页面组件中维护。
