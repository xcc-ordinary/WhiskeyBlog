# 个人开发者网站：第一版设计

## 目标与范围

构建并公开发布一个面向简体中文读者的个人网站，呈现一名正在成长的开发者。第一版的目标是完成从设计、开发、测试、版本控制到生产部署的完整工作流，而不是一次性构建社区或后台产品。

首发内容为一段个人介绍、两个带详情页的项目，以及一篇记录建站过程的博客文章。主导航固定为首页、关于我、项目、博客；GitHub 与专用公开邮箱是行动链接，放在首页和页脚。

第一版不包含账户、评论、点赞、在线联系表单、广告或行为画像。流量只通过 Vercel 的轻量分析了解。

## 架构

采用 Next.js App Router、TypeScript 和 Tailwind CSS。页面位于 `app/`，只组合内容和界面；可复用 UI 位于 `components/`；内容读取、校验和纯转换逻辑位于 `lib/`；MDX 源文件位于 `content/posts/` 与 `content/projects/`；测试按单元测试和浏览器端到端测试组织。

文章和项目都是本地 MDX 文件。每个文件提供明确的元数据：标题、摘要、发布日期、标签以及可选的封面信息。构建阶段校验元数据，生成列表和详情路由；错误或缺失的内容应在本地构建时失败，而不存在的页面应显示 404。

选择 Next.js 而非纯静态生成器或前后端分离架构，是为了在单仓库中练习现代 React、内容建模、质量检查和部署，并为后续的数据库、认证和表单留出自然的扩展路径。

## 视觉与交互

视觉方向为具有苹果式清晰层级、精致排版和即时反馈的活力设计，而非单调黑白。项目截图与 CSS 生成的抽象色彩和形状是主要素材，不使用未经授权的图库图片。

设计以桌面浏览器为第一目标：先建立宽屏阅读、导航、信息密度和项目网格，再为平板与手机设计明确的断点重排。小屏幕将收拢导航、把项目网格变为单列，并重新安排字号与留白，而非简单缩放桌面版。

颜色、间距、圆角、阴影和亮暗主题通过 CSS 自定义属性形成设计令牌，Tailwind 消费这些令牌。界面使用系统字体栈，确保中文正文清晰易读。默认跟随系统浅深色偏好，并允许访问者手动切换。

动效服务于反馈和层级：按下状态即时可见，卡片悬停有轻微提升，内容进入使用短促淡入。所有动效尊重 `prefers-reduced-motion`；键盘焦点、色彩对比度、图片替代文本和语义化结构均为验收要求。

## 质量与发布

Vitest 覆盖关键内容读取与转换逻辑，Playwright 使用一条浏览器冒烟路径验证首页、项目详情页和文章详情页。每次提交前应通过格式检查、类型检查、单元测试与端到端冒烟测试。

代码仓库公开托管于 GitHub，严禁提交凭据和 `.env` 文件。推送后由 Vercel 自动生成预览与生产部署；先使用 Vercel 子域名，稳定后再绑定自定义域名。首次生产发布前，需要手动检查桌面主流浏览器、窄屏重排、亮暗主题、键盘导航、页面标题和分享预览。

## 学习与验收方式

不按固定日历排期。每个里程碑只包含一个可见成果，并配套四件事：它为什么存在、完成它所需的最少知识、动手实现任务，以及清晰的验收命令或浏览器检查。遇到障碍时，先定位最小问题，再查阅相应官方文档并立即应用。

第一阶段的可见成果是一个可运行的 Next.js 空壳，包含桌面优先的首页骨架和基础主题令牌。后续依次建立内容管道、页面与交互、测试、GitHub/Vercel 发布和上线检查。
