# Studio · 写作工作台

Studio 使用当前 Personal Journal 的颜色、字体、刊头与细分栏线。操作区域以无衬线字体保持清楚，文章预览遵循 `app/reading.css` 的公开博客阅读样式。

## 写作与导入

- 在 `/studio/writing` 新建文章，在 `/studio/projects` 新建作品；两者使用同一个编辑器。
- 默认进入即时排版写作：点击一段即可编辑其 Markdown，移开焦点后显示排版。标题、摘要和正文会随内容自然展开，不使用内部滚动框；可点击“即时排版”切换到完整 Markdown 源码。“对照”同时显示 Markdown 和阅读稿，“预览”显示公开页面的标题、作者、日期、封面和正文排版。
- “专注”暂时收起网站刊头和导航；再次点击或按 Escape 返回。
- “导入 .md”支持 `.md`、`.markdown`、`.mdx`，也可拖入文件。只解析 Markdown 与 YAML，不执行 MDX / JavaScript。
- 导入时识别标题、摘要、日期、标签、封面及兼容的项目字段。没有文章信息时，尝试提取一级标题和首段。已有内容的 slug 保持不变。
- 导入不会发布，可点击“撤销导入”还原导入前的内容。本地附件路径不会自动上传或被替换；请手动上传所需配图。

## 图片与 Markdown

工具栏可插入小标题、粗体、斜体、链接、引用、列表、代码和正文图片。正文区支持粘贴图片与拖入图片；封面在发布设置中管理。每张图最大 3.75MB，支持 JPG、PNG、WebP、GIF。

项目与文章配图上传后已有公开地址，发布操作决定它们是否显示在这篇内容中。私人摄影原图仍使用独立的私有照片存储。

`components/markdown-document.tsx` 是公开博客和本地预览的同一份渲染实现，包含 GFM 表格、任务列表、数学公式、代码高亮、Mermaid、Obsidian 提示块、脚注与安全 HTML。预览不再为每次输入发送服务器请求；笔记内链使用页面打开时获取的已发布内容索引。

## 草稿与发布

- 修改后自动备份到当前浏览器的本地存储；Ctrl / ⌘ S 或“备份草稿”可立即备份。跨文章导航前也尝试保留备份。
- 再次打开时，如有本机草稿，会询问恢复或保留当前版本，不自动覆盖已发布内容。
- 这些备份属于当前浏览器，不是云端草稿；切换浏览器或清除网站数据后不可依赖它。需要可携带副本时用“导出”下载含文章信息的 `.md`。
- 打开独立的“发布设置”弹窗，核对日期、标签和可选目录封面。地址、署名、首页排序和英文资料放在“更多设置”。新内容点击“发布文章 / 项目”，已有内容点击“更新文章 / 项目”，此时才调用云端保存并公开展示。
- 发布失败保留正文和重试入口。发布成功后清除本篇的本机草稿。

## 验证

`npm run test:unit` 覆盖实际导入解析、鉴权、预览一致性、草稿恢复、上传插图及发布失败恢复。

`npm run test:studio` 使用真实工作台组件与共享样式，在组件测试服务中验证桌面和 390px 手机布局、字号、溢出、导入、导出和发布交互。其保存、上传与导入服务使用测试替身，不会向生产数据库发布测试内容，也不能代替真实账号下的生产上传验证。测试截图写入 `design/studio-journal-v2-2026-10-19/`，覆盖长正文自然展开、段落编辑、图片去重、搜索切换弹窗、照片网格与照片编辑。

`npm run test:e2e` 检查真实 Next 应用的公开博客、项目、导航及登录入口。生产部署与真实所有者的首篇发布另行验收。

## 阅读与照片

- 自动从正文选择的项目封面继续用于首页和项目目录。公开文章与 Studio 阅读稿在正文已经配图时不额外插入目录封面，即使封面和正文图片因重复上传而具有不同文件地址。正文无配图时仍正常展示独立封面。
- 封面保持原始比例，博客标题与目录采用主页相同的编辑式字体和细分栏线。
- 文章目录可以同时按标签与关键词搜索；照片资料库采用缩略图网格、状态筛选与标题/地点搜索。
- 内容切换与发布弹窗支持键盘、Escape、焦点限制及关闭后返回触发按钮。上传照片仍先建立私密草稿，照片编辑与公开操作保持原有后端权限。
