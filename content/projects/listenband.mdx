# ListenBand

ListenBand 是一个面向 Obsidian 桌面端的语言学习插件，把视频听力、带时间戳的逐句稿和词汇积累放进笔记里。

支持 YouTube 与 Bilibili 视频学习，以及本地字幕和双语文稿导入。点击时间戳回到对应片段，按需翻译句子，使用离线英汉词典查词，在自己的笔记中反复听、读和积累。

文稿、词典与翻译缓存尽可能保存在本地；AI 翻译按需调用用户配置的服务。

[查看 GitHub 项目与安装说明](https://github.com/xcc-ordinary/ListenBand)
