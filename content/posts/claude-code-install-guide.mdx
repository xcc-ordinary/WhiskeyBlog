# Claude Code 最新版安装教程

Claude Code 是运行在终端里的编程智能体。它不只是回答问题，还能读取项目、修改文件、执行命令和检查结果。下面从安装开始，带你完成第一次可用的会话。

## 1. Windows 准备工作

原生 Windows 用户建议先安装 [Git for Windows](https://git-scm.com/download/win)。Claude Code 在 Windows 上会用到 Git Bash；macOS、Linux 或已经使用 WSL 的用户可以直接进入下一节。

安装 Git for Windows 时，保持默认选项通常就够了。完成后重新打开 PowerShell，再运行：

```powershell
git --version
```

能看到版本号，就说明 Git 已经进入 PATH。

## 2. 安装 Claude Code

选择与你的系统对应的一种方式即可，不需要全部执行。

### Windows PowerShell

```powershell
irm https://claude.ai/install.ps1 | iex
```

### WinGet

```powershell
winget install Anthropic.ClaudeCode
```

### macOS / Linux / WSL

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

macOS 也可以使用 Homebrew：

```bash
brew install --cask claude-code
```

原生安装器会自行携带所需运行环境。若你明确需要 npm 方式，请先确认 Node.js 版本不低于 18，然后运行：

```bash
npm install -g @anthropic-ai/claude-code
```

不要给 npm 命令加 `sudo`，否则后续更新容易遇到权限问题。

## 3. 验证命令与 PATH

安装完成后先关闭当前终端，再打开一个新的终端：

```powershell
claude --version
```

如果出现“找不到 claude 命令”，先检查 Windows 的用户 PATH 中是否包含：

```text
%USERPROFILE%\.local\bin
```

你可以在“开始菜单 → 编辑系统环境变量 → 环境变量 → 用户变量 → Path”中添加它。添加后一定要重新打开终端。

如果仍然无法启动，运行诊断：

```powershell
claude doctor
```

在 Claude Code 会话内输入 `/login` 可以重新选择登录方式，输入 `/logout` 可以退出当前账户。

### 关于第三方 API 和切换工具

有些工具可以改写 Claude Code 的环境变量或请求地址，用来连接第三方网关。它们并不等于 Anthropic 官方服务。使用前至少确认三件事：

1. 密钥是否只保存在本机，而不是上传到未知服务器；
2. 对方是否清楚说明模型来源、计费和日志保留策略；
3. 是否能随时撤销密钥，并为密钥设置余额或权限上限。

不要把 API Key 发到聊天、截图、公开仓库或群聊里。切换登录方式后，如果仍然走 API 计费，检查系统中是否残留 `ANTHROPIC_API_KEY`。

## 5. 开始第一次项目会话

先进入你希望 Claude Code 工作的目录，再启动：

```powershell
cd "D:\你的项目目录"
claude
```

第一次任务不要只说“帮我看看”。给它明确目标、范围和完成标准，例如：

```text
先阅读 README 和 package.json，告诉我这个项目怎么本地启动。
不要修改文件。最后给我一组可直接复制的 PowerShell 命令。
```

确认它理解项目后，再让它实施改动：

```text
修复登录按钮在手机端被遮挡的问题。
保留现有视觉风格，完成后运行相关测试并说明还没有验证的部分。
```

## 6. 常见问题与卸载

### 安装完成但命令不存在

重新打开终端，检查 PATH，再运行 `claude doctor`。在 WSL 中还要确认调用的是 Linux 环境里的命令，而不是 Windows 的 Node.js 或可执行文件。

### 登录后一直等待

远程 SSH、容器或严格防火墙可能阻断本机回调。按照终端给出的手动验证地址完成登录，并把返回的验证码粘贴回终端。

### 如何更新

原生安装一般会自动更新，也可以手动执行：

```powershell
claude update
```

通过 Homebrew 或 WinGet 安装的版本，应分别使用对应包管理器更新。

### 如何卸载

优先使用与你安装时相同的包管理器，或在 Windows“设置 → 应用 → 已安装的应用”中卸载。只有确认不再需要历史会话、设置和自定义工具时，才考虑手动删除 `~/.claude` 等配置目录；删除前请先备份。
